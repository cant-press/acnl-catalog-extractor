Getting your save

On a modded 3DS, back up the game with Checkpoint or JKSV, then copy garden_plus.dat from that backup folder on the SD card. Once a game has the Welcome amiibo update it uses this file, even if an old garden.dat sits next to it.

What stays on your device

The file is read by this page in your browser. Nothing is uploaded, and the save is never changed.

Restoring into Planner

This writes a new file and leaves your original backup alone, so keep the original in case you need to go back. Existing ticks are kept, except villagers and Misc, which are replaced with what the save holds. Museum donations and projects come from the town. Exteriors only cover what is on the house now, because the save keeps no record of past ones. The app's item names are inferred, so check what it reports after restoring.

Rare items

Lists and RV sellers come from Nookipedia. Items marked with an amiibo need that amiibo or card scanned to bring the RV to your campground.

How it reads the catalog

Each player has a bitfield of unlocked items at player + 0x6C20, with one bit per item ID starting from 0x2000. If a catalog was filled with a save editor, it will show as complete. Item names come from Marc Robledo's ACNL Save Editor (MIT licence). Unofficial fan tool, not affiliated with Nintendo or with Planner for AC: NL.
